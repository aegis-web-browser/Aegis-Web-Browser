# Aegis Web 5.9.2 — bêta 5 (Windows x64)

**Préversion publique pour essais — pas une version stable.**

## Nouveautés
- Aegis Start adapté aux différentes résolutions et correction du bug qui le laissait affiché par-dessus les sites visités.
- « Bon plan du jour » : recherche de réductions Steam et de jeux temporairement offerts sur Epic Games, uniquement lorsque les données de boutiques permettent de vérifier l'offre. En cas d'échec, aucune promotion n'est inventée.
- Aegis Run : ouverture automatique en cas de perte de connexion ; proposition de jeu après 12 secondes de chargement d'une page lente, sans interrompre celui-ci.
- Contrôles clavier du jeu corrigés (Espace / haut : sauter ; bas : glisser ; P : pause).
- Contrôle parental expérimental : code PIN, quota quotidien de temps d'écran et domaines bloqués. Il agit dans Aegis Web, pas au niveau de Windows ; une personne ayant les droits administrateur peut le contourner.
- Suppression des raccourcis Arcade et Chat ; Focus reste accessible indépendamment.

## Installation
Télécharger **Aegis-Web-Setup-Windows.exe** ci-dessous. Installation Windows 10/11 x64. Programme non signé numériquement : Windows SmartScreen peut afficher un avertissement.

**Attention :** préversion non auditée. Les tests automatiques et la compilation sont réussis, mais la détection de réseau, l'interface selon les écrans et le contrôle parental nécessitent des tests réels. Sauvegarder les données Aegis avant d'installer cette bêta. La stable 5.9.1 reste disponible séparément.

## ENGLISH
Public **beta/pre-release**, not the stable release. Responsive Aegis Start fix (including the overlay blocking navigation), real storefront deal verification, automatic offline runner and 12-second slow-page play prompt, keyboard fixes, experimental app-only parental controls and separate Focus. No Arcade or Chat in this build. Windows x64 installer is unsigned. Test carefully and back up your data; stable 5.9.1 remains unchanged.
