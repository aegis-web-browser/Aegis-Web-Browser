# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately to the repository maintainer using GitHub's **Security** tab (Private vulnerability reporting, if enabled). Do **not** publish exploit details in a public issue before coordination.

## Current verification status

The 5.8.5.1 application JavaScript was recovered from the Windows installer and passed a basic Node.js syntax check. This is **not** a malware-free certification, full security audit, or proof that official binaries were built from this repository.

Until a documented and independently verified build pipeline is established, the downloadable installers must be treated separately from source-code transparency.
